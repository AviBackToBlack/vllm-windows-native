## Important limitations

- FA3 is intentionally absent because the upstream FA3 path does not support Blackwell SM120.
- DeepGEMM 2.6.1 Windows binary/JIT plumbing is built and importable, but upstream DeepGEMM has no SM120 runtime dispatch. Real `bf16_gemm_nt(...)` therefore reports `Unsupported architecture`; SM120 must not be routed into the SM100 backend blindly.
- This milestone accepts only one GPU. Windows NCCL, Tensor Parallel and Pipeline Parallel remain future work.
- A non-fatal PyTorch/c10d hostname connection warning (`WinError 10049`) remains visible during world-size-1 initialization and should be investigated before release polish.
